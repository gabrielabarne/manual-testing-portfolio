# Manual Testing Portfolio | Gabriela Barné

Welcome to my Software Quality Assurance portfolio!

## About Me

I'm Gabriela Barné, a QA Analyst with over 6 years of experience in software testing and a background in Product Ownership and IT support.

My main expertise includes Functional Testing, REST API Testing, Integration Testing, Regression Testing, Exploratory Testing, End-to-End (E2E) Testing, and Mobile Testing (iOS and Android).

I believe software quality is a shared responsibility. My approach focuses on understanding business requirements, identifying risks early, creating meaningful test scenarios, and collaborating with development teams.

## Portfolio Objective

This repository is dedicated to documenting practical manual testing projects, including test planning, scenario design, defect reporting, execution evidence, and quality assessments.
