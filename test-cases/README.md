# Test Cases

This folder contains manual test cases and BDD scenarios for the applications under test.

## Test Case Structure

Each test case may include:
- Test Case ID
- Test Objective
- Preconditions
- Test Steps
- Expected Results
- Actual Results
- Execution Status (Pass, Fail, Blocked, Not Run)
- Priority and Severity (when applicable)

## Testing Techniques

Test scenarios may be designed using:
- Equivalence Partitioning
- Boundary Value Analysis
- Decision Tables
- State Transition Testing
- Exploratory Testing
- BDD/Gherkin (Given, When, Then)
