# Bug Reports

This folder contains documented software defects identified during manual testing activities.

## Bug Report Structure

Each bug report may include:
- Bug ID and title
- Description
- Environment and application version
- Preconditions
- Steps to reproduce
- Expected result
- Actual result
- Severity and priority
- Evidence (screenshots, videos, or logs)
- Bug status

## Objective

To provide clear, reproducible, and well-documented defects that support efficient investigation, communication, and resolution by development teams.
