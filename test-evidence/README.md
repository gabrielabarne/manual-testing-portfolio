# Test Evidence

This folder contains evidence collected during manual test execution.

## Evidence Types

- Screenshots of application behavior
- Screen recordings of test execution
- Visual evidence of defects
- Evidence supporting successful test scenarios

## Naming Convention

Evidence files should follow a consistent naming convention:

`TC-001_login_success.png`
`TC-002_invalid_credentials.png`
`BUG-001_login_error.png`

## Best Practices

- Link each evidence file to a test case or bug report.
- Remove or mask sensitive and personal information.
- Use clear and descriptive filenames.
- Keep evidence organized by application or feature.
